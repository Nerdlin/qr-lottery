# 🎰 Интерактивная QR-Лотерея с Рандомайзером для Мероприятий

Современная интерактивная система розыгрыша призов для презентаций, конференций, корпоративов и праздников.

Гости сканируют QR-код на большом экране со своих смартфонов, регистрируются, и их карточки в реальном времени появляются на экране. По готовности (например, 50 человек) ведущий запускает зрелищный рандомайзер, карточки динамично подсвечиваются, и эффектно определяются **3 победителя** с конфетти и фанфарами!

---

## ✨ Возможности

- 📱 **Работа через GitHub Pages:** полностью статичный фронтенд, не требует собственного сервера или баз данных. Работает прямо из браузера через защищенные веб-сокеты (WSS Cloud MQTT).
- 💻 **Локальный режим (Node.js):** если в зале нет интернета, можно запустить локально через ноутбук по локальному Wi-Fi (`npm start`).
- ⚡ **Real-time обновление:** появление участников на экране мгновенное (без перезагрузки страниц).
- 🎲 **Зрелищный рандомайзер:**
  - Обратный отсчёт (3, 2, 1, 🔥);
  - Бегущая подсветка карточек с замедлением (эффект рулетки фортуны);
  - Синтезированные звуковые эффекты (щелчки, отсчёт, победные фанфары через Web Audio API);
  - Поочередное определение 3, 2 и 1 места для максимальной интриги;
  - Салют конфетти (`canvas-confetti`) и финальный пьедестал победителей.
- 📱 **Мгновенное уведомление на смартфоне победителя:** телефон вибрирует, осыпается конфетти и поздравляет с победой!
- 🛠️ **Панель ведущего:**
  - Кнопка **«+50 демо»** для быстрой репетиции без гостей за 1 клик;
  - Настройка цели участников (по умолчанию 50);
  - Сброс розыгрыша;
  - Полноэкранный режим (Full Screen).

## 🚀 Как запустить на GitHub Pages (Бесплатно, без сервера)

1. **Создайте новый репозиторий на GitHub** (например, `qr-lottery`).
2. **Загрузите все файлы проекта в репозиторий:**
   ```bash
   git init
   git add .
   git commit -m "Initial release QR lottery"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/qr-lottery.git
   git push -u origin main
   ```
3. **Включите GitHub Pages:**
   - Откройте репозиторий на GitHub -> **Settings** -> **Pages** (в меню слева).
   - В разделе **Build and deployment** выберите Source: **Deploy from a branch**.
   - Выберите ветку **main** и папку **/(root)**, нажмите **Save**.
4. Через 1-2 минуты сайт откроется по адресу:
   `https://ВАШ_НИК.github.io/qr-lottery/`

Откройте этот адрес на ноутбуке, подключенном к проектору или ТВ. QR-код сгенерируется автоматически и будет вести прямо на форму для участников!

---

## 💻 Локальный запуск на ноутбуке (по локальному Wi-Fi)

Если у вас нет интернета на площадке или вы хотите запустить всё локально:

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер:
   ```bash
   npm start
   ```
3. В терминале отобразится адрес для ноутбука и ссылка для участников.

## 📁 Структура проекта

- `index.html` — экран для проектора / ТВ (главная страница)
- `screen.css` — стили для большого экрана (неоновый праздничный дизайн)
- `screen.js` — логика экрана, генерация QR-кода, алгоритм рандомайзера
- `join.html` — мобильная страница участника
- `join.css` — мобильные стили
- `join.js` — отправка данных участника и показ победного экрана
- `audio.js` — звуковой движок на Web Audio API (без внешних файлов)
- `lib/` — библиотеки `qrcode.min.js`, `confetti.browser.js`, `mqtt.min.js`
- `server.js` — дополнительный Node.js сервер для локальной работы без интернета
